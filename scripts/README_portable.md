## 一、这份软件是什么？

「个人文献库」是一个**跑在自己电脑上的论文管理网页**：

| 能力 | 说明 |
|---|---|
| 📥 自动解析 | 丢一个 PDF 进去，自动读出标题、作者、期刊、年份、全文、所有图表和图注 |
| 🔍 智能搜索 | 标题、正文、图注一起搜，中文英文都能搜，结果按相关度排序 |
| 📖 站内阅读 | 不用下载、不用开 Adobe，直接在网页里读 PDF，可缩放、可全屏、一屏看完整页 |
| 💬 AI 问答 | 挂上 API Key 后，可以让 AI 帮你提炼实验条件、对比图表数据、剖析反应机理 |
| 🧭 横向对比 | 多选同类文献，一键生成化学/材料多维实验对比矩阵与跨篇深度 AI 综述，支持导出 Excel/Markdown |
| 🗂️ 分类管理 | 按课题建分类（如"钙钛矿""电催化"），电脑文件夹和网页分类一一对应 |

**它完全离线运行**，所有文献只存在你自己的电脑里，不会上传到任何服务器。
（只有你主动点「AI 总结 / AI 问答」时，才会把该论文的内容发给你自己填的 AI 服务商。）

## 三、第一次使用（照做就行，共 4 步）

### 第 1 步：解压

1. 把 `个人文献库_便携版.zip` 放到你想长期存放的位置
   （建议 `D:\个人文献库\`，**不要放在 C 盘的"下载"里，也不要放在微信/QQ 的临时目录**）
2. 右键 → **「全部解压缩」**（Windows 11 也可以直接右键 → 全部解压缩）
3. 解压后会得到一个文件夹：`个人文献库_便携版`

> ⚠️ **重要：一定要先解压再运行。**
> 直接在压缩包里双击启动按钮会失败——因为程序需要读取同一目录下的运行环境文件。

> ⚠️ **解压路径里尽量不要有特殊符号**，中文没问题，但避免 `#`、`%`、`&` 这类字符。

### 第 2 步：双击启动

打开 `个人文献库_便携版` 文件夹，你会看到这些文件：

```
个人文献库_便携版\
├── 启动个人文献库.bat      ← 双击这个！（黑色窗口，能看到进度）
├── 启动个人文献库.vbs      ← 或者这个（无窗口静默启动）
├── 退出个人文献库.bat      ← 用完想彻底关闭时双击
├── 使用说明.html          ← 就是本说明，可随时打开
└── app\  runtime\         ← 程序本体，不要动、不要删
```

**双击 `启动个人文献库.bat`**，会弹出一个黑色命令行窗口：

```
  [1/3] 检查运行环境…
  [2/3] 正在启动服务（首次启动约需 20～40 秒）…
  [3/3] 启动完成后浏览器会自动打开…
```

### 第 3 步：等它自己打开

- 大约 **20～40 秒**后，浏览器会**自动打开**一个页面：`http://localhost:8501`
- 看到「个人文献库」的界面，就说明成功了
- 同时，你的**桌面上会自动出现一个「个人文献库」图标**，以后直接双击它就行

> 如果浏览器没自动打开：手动打开浏览器，在地址栏输入 `localhost:8501` 回车即可。
> 那个黑色窗口出现 `已启动完成！` 后 5 秒会自动关闭，**这是正常现象**，不影响使用。

### 第 4 步：添加你的第一篇文献

首次打开时，页面中间会有一个欢迎引导卡片，告诉你三种添加方式。任选一种：

#### 方式 A：直接在网页里拖入（最简单）

1. 页面上的「📥 快速添加第一篇文献」框
2. 把 PDF 从文件夹**拖进虚线框**（或点击框内选择文件）
3. 选一个分类（没有就选「根目录」，或新建一个）
4. 点 **「🚀 立即导入入库」**
5. 等几秒，它会自动解析标题、正文、图表 → 完成

#### 方式 B：放进文件夹后一键扫描（适合批量）

1. 打开软件目录里的 **`app\【文献存放处】`** 文件夹
2. 把一堆 PDF 复制进去（可以自己建子文件夹，子文件夹名就是分类名）
3. 回到网页，点**左侧边栏**的 **「🔄 扫描刷新文献库」**
4. 它会自动把所有 PDF 挨个解析入库（篇数多时慢一点，有进度条）

#### 方式 C：直接绑定你已有的论文文件夹

1. 左侧边栏 → 「⚙️ 设定文献库总大文件夹」
2. 点 **「🖥️ 弹出 Windows 文件管理器选择」**，选中你电脑上已有的论文大目录
3. 确认 → 再点「🔄 扫描刷新文献库」

> 三种方式数据完全一样：**PC 文件夹结构和网页分类是一一对应的**，你以后在电脑上怎么放，网页就怎么显示。

## 四、日常怎么用

### 找文献

- 顶部搜索框：输入关键词（标题、作者、内容里的词都行），回车
- 左侧边栏「📂 文献分类与导航」：按分类筛选
- 搜索支持中文，例如搜「过电位」能命中正文里的「过电位 320 mV」

### 读文献

点开任意一篇，从上到下是：

1. **📖 顶部操作栏**：复制引文（BibTeX / GB/T 7714 / APA）、新标签全屏阅读
2. **版式选择**：默认「⚖️ 黄金双栏研读」——左边读原文、右边问 AI
   - 喜欢大屏：切到「🖥️ 沉浸巨幕阅读」，PDF 占满整宽
   - 页面适配：可选「📄 适应整页」（一屏看完整页）或「↔️ 视窗撑满」（横向撑满）
   - 阅读器内快捷键：`P` 整页、`W` 撑满宽、`←/→` 翻页、`+/-` 缩放、`F` 满屏
3. **📝 结构化摘要与深度解读**：AI 或解析器给出的全文要点
4. **🖼️ 全篇图表图注全景画廊**：所有图表 + 原始图注，可点「🔍 看原图」按原分辨率查看

### 用 AI 问答（可选）

AI 功能需要你自己的 API Key（DeepSeek 或 Claude 都支持）：

1. 左侧边栏 → 「🤖 AI 问答与摘要配置」
2. 选择服务商（推荐 DeepSeek，便宜、快），粘贴你的 API Key
3. 保存后，在任意文献的右侧「💬 论文专属 AI 问答顾问」里提问
4. 也可以用「🔬 常用科研深度提问快捷指令」里的 4 个预设问题一键提问

> 不填 API Key 也能正常用：解析、搜索、阅读、看图全部不受影响，只是没有 AI 回答。

### 做多篇文献横向对比（全新）

想把多篇同领域的论文（例如同类催化剂、同类反应或 MOF/COF 材料）拉通比对？

1. **多选加篮**：在「📖 文献库概览」的论文卡片右下角，点击 **「＋ 对比」** 选入对比篮（顶部会实时弹出浮动提示）；
2. **进入工作台**：切换到顶部第四个页签 **「🧭 横向对比」**；
3. **选择学科模板**：
   - 专门针对化学/材料学科内置了 **有机合成/催化**（11 维：催化剂/条件/产率/选择性/底物/机理/表征/局限性等）、**电化学/电催化**、**功能材料** 与 **通用对比** 模板，还可自由输入自定义维度；
4. **一键抽取结构化矩阵**：
   - 点击「🚀 抽取结构化数据」，AI 逐篇抽取统一字段与原文事实证据；
   - **持久化本地缓存**：提取过的数据自动存库，换组合对比时直接秒级读取，**绝不重复消耗 Token**；
5. **AI 跨文献深度综述与导出**：
   - 查看横向对比矩阵，点击「🧠 生成跨文献深度横向综述」，深入剖析文献间的共识、关键性能差异、演进脉络与研究空白；
   - 支持一键导出 **Markdown 研报** 与 UTF-8 BOM 编码的 **CSV 矩阵表格**（Excel 双击直接打开，无乱码）。

## 六、想换个地方放 / 发给别人

### 移动位置

- 随便移动整个 `个人文献库_便携版` 文件夹都行（数据都在里面）
- 移动后，**双击一次文件夹里的 `启动个人文献库.bat`**，桌面快捷方式会自动指向新位置
- 如果桌面图标失效了：删掉它，重新双击一次启动按钮就会自动重建

### 备份

要备份你的文献库，**整个文件夹复制一份**即可（重点是 `app\data` 和 `app\【文献存放处】`）。

### 以后作者发布了新功能，我该如何升级？（文献会丢吗？）

**绝对不会丢失任何文献！**
因为你的文献 PDF 与数据库都安全存放在 `app\data` 和 `app\【文献存放处】` 中，而更新仅仅是更新程序代码文件。

**升级超简单（2 步搞定）：**
1. 收到作者发来的微型 `个人文献库_升级补丁.zip`（仅 1MB 不到）并解压；
2. **任选一种升级方式：**
   - **方式 A（全自动）**：把解压出的文件夹放在和你的【个人文献库_便携版】同一目录下，双击里面的 **`【双击我一键升级·保留文献】.bat`**；
   - **方式 B（手动拖放）**：直接把解压出来的 `app` 文件夹，拖进你的文献库主文件夹中**覆盖同名文件**。
3. 重新双击「启动个人文献库.bat」，所有原有文献、图表与阅读记录 100% 毫发无损，新功能立即解锁！

## 七、常见问题（出问题先看这里）

### Q1：双击启动按钮，窗口一闪就没了

- 确认你是**解压后**在文件夹里双击的，不是直接在压缩包里双击
- 右键 `启动个人文献库.bat` → 「以管理员身份运行」再试一次
- 检查 `runtime\python.exe` 是否存在（不存在说明解压不完整，重新解压）

### Q2：提示「启动失败」或窗口停在某一步不动

- 很可能是**杀毒软件拦截**。360 / 火绒 / Windows Defender 有时会误报 Python 程序
  → 把整个文件夹加入白名单/信任目录，再试一次
- 也可能是 **8501 端口被占用**（比如上次没关干净）
  → 先双击 `退出个人文献库.bat`，再重新启动

### Q3：浏览器打开是空白页 / 一直转圈

- 刷新一下（F5）
- 换 Edge 或 Chrome 打开 `http://localhost:8501`
- 仍不行：双击 `退出个人文献库.bat` → 再双击启动

### Q4：扫描后没看到文献

- 确认 PDF 确实在 `app\【文献存放处】` 里（或你绑定的那个大文件夹里）
- 确认文件是 `.pdf` 结尾、能正常打开（加密/损坏的 PDF 会跳过）
- 再点一次「🔄 扫描刷新文献库」

### Q5：PDF 在网页里显示不出来

- 用 Edge 或 Chrome（老旧 IE 不行）
- 极少数扫描版 PDF 无法提取文字，但仍可阅读原件、看图

### Q6：AI 没有回答

- 检查 API Key 是否填对、余额是否充足
- 检查电脑能否正常联网
- 不填 Key 不影响其它功能

### Q7：能卸载吗？

- 没有任何注册表残留、没有系统服务。想删就删掉整个文件夹；
- 记得顺手删掉桌面的「个人文献库」图标。
