# 合并新增端点契约（10 条）

> 这 10 条是 Sci-lib 没有的 PaperLibrary 能力端点。前端 3 个新视图（figures / compare / deep）与
> tools/contract_check.py 都以本文为准。形状一旦写入，前后端不得各自改动；要改先找 Lead。

## 1. GET /api/figures

图表画廊（跨文献）。

请求：q（可选，图表描述/图注全文检索）、paperId（可选）、type（可选，figure/table/scheme/chart 等）、
page（≥1，默认 1）、pageSize（1-100，默认 48）。

响应 200：

    {
      "ok": true,
      "items": [{
        "id": 12, "paperId": "d61693e220deafac", "paperTitle": "…",
        "figIndex": 3, "caption": "Fig. 3 …", "contextText": "…",
        "aiDescription": "", "figureType": "", "aiConclusion": "",
        "imagePath": "images/<paperId>/fig-3.png", "hasImage": true
      }],
      "total": 1, "page": 1, "pageSize": 48, "pageCount": 1
    }

## 2. GET|HEAD /api/figures/:id/image

图表图片流：Content-Type 按扩展名；支持 Range/ETag（复用 ctx.send_file）。
404：{ok:false,error:"图表不存在"} / {ok:false,error:"图表文件不存在"}。

## 3. GET /api/papers/:id/figures

    { "ok": true, "paperId": "…", "figures": [<同上 item，去掉 paperTitle>] }

## 4. POST /api/papers/:id/figures/extract

从该文献的 PDF 重新提取图表（PyMuPDF 渲染 + 图注 bbox 匹配）。

请求：{ "force": false }（可选；true 覆盖已有图表记录）
响应：{ "ok": true, "extracted": 12, "figures": [<同上>] }
400：无关联 PDF / PDF 不存在；500：提取失败（error 带原因）。

## 5. GET /api/compare/templates

    { "ok": true, "templates": [
      { "id": "synthesis", "name": "合成路线对比",
        "desc": "…", "fields": ["原料", "条件", "产率", "表征"] }
    ]}

至少 4 套（对齐 PaperLibrary compare_engine 的模板）；无 Key 时也能列出。

## 6. POST /api/compare

横向对比（Map-Reduce；无 Key 时只输出本地可算字段与资料摘要，不编造）。

请求：{ "paperIds": ["id1","id2"], "template": "synthesis" }
响应 200：

    { "ok": true, "result": {
        "template": "synthesis", "oneLine": "…",
        "sections": [{ "title": "原料", "rows": [{ "paperId": "id1", "value": "…" }] }],
        "usage": { "prompt_tokens": 0, "completion_tokens": 0 }
    }}
400：paperIds 少于 2 条 / 超过 8 条；404 任一文献不存在。

## 7. GET /api/papers/:id/deep-analysis

    { "ok": true, "analysis": null | {
        "paperId": "…", "updatedAt": "…", "model": "…",
        "fields": { "研究问题": "…", "方法": "…", "…": "…" },
        "scores": { "创新性": 4, "严谨性": 4, "影响力": 3, "可复现性": 3, "可读性": 4 },
        "oneLine": "…"
      }}

## 8. POST /api/papers/:id/deep-analysis

请求：{ "force": false }（可选；已存在且非 force 时直接返回缓存）
响应：{ "ok": true, "analysis": {<同 §7>}, "saved": true }
无 Key：返回本地降级结果（metadata + 摘要 + 五维启发式评分，fields 里标注「未配置大模型，仅本地分析」），
仍必须 200，不得 400/502（离线目标 G2）。404：文献不存在。

## 9. GET /api/terms/search

中英术语检索（PaperLibrary 119 条术语表）。

请求：q（必填，中英均可，子串/别名匹配）、limit（默认 20，1-100）。
响应：{ "ok": true, "query": "…", "items": [{ "zh": "亲核取代", "en": "nucleophilic substitution",
"aliases": ["SN2"], "field": "有机化学" }], "total": 1 }
400：q 为空。

## 10. GET /api/export/obsidian

Obsidian 导出：zip 文件流，Content-Disposition attachment; filename="paperlibrary-obsidian-<date>.zip"。
内容：每篇一个 .md（frontmatter：title/year/authors/tags/doi；正文含摘要、笔记、AI 总结、图表链接），
zip 内 media/ 放引用到的图表；只导出有内容的字段。500：导出失败（error 带原因）。
