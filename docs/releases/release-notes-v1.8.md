# PaperLibrary v1.8.0 更新说明

发布日期：2026-11-17
版本：1.8.0（tag v1.8，Windows 10.0.17763 及以上，x64）

## 本次主要变更

本版本完成了 PaperLibrary 的整包更新机制，并加入“立即安装”与可选自动下载。更新过程中用户数据保留在 data/，程序文件替换与失败回滚由包外 helper 执行。

### 新增功能

- 设置页“立即安装”：确认后立即关闭应用并安装，安装完成后自动重新打开；确认框明确说明关闭、自动重开、数据保留和 AI 请求中断。
- 自动下载开关：默认关闭；开启后只自动下载，不会静默安装，下载完成仍需点击“立即安装”。
- 完整更新时序：等待启动器/端口/文件锁 → 数据备份 → 程序备份 → 替换 → 健康检查 → 成功清理/失败回滚。
- journal 状态机与启动恢复：安装中断、强杀或断电后，下次启动可恢复旧版本；install.lock 阻止安装中双开，过期锁可安全清理。
- 健康检查口径 B：检查 HTTP 200、ok、app、product 和版本，连续成功 2 次才判定成功；失败自动回滚并记录具体 code。
- 磁盘/权限预检：检查 300 MB 余量、Program Files 限制、程序目录可写、helper 哈希、apply/staging 完整性。
- 安装期文件占用重试：仅对共享/锁冲突按文件重试（300 ms，最多 21 秒）；超时取消更新、回滚并提示。
- 发布与安全检查：Ed25519 签名清单、SHA-256、下载主机白名单；发布包不包含用户 data/。

### 修复与改进

- 修复更新助手启动新版本时管道继承导致等待不退出/日志不完整的问题。
- 修复安装锁过期与中断 journal 无法自动恢复的问题。
- 修复健康检查失败原因不明确的问题，现区分 timeout/http/json/not-ok/app/version。
- 修复替换/备份在杀软或索引器占用文件时直接失败的问题，改为有限重试后回滚。
- 修复应用关闭时未等待 Python 服务退出、安装中重复启动等问题。
- 改进更新错误提示：失败窗口保持，启动时显示失败原因和日志路径。

## 注意事项

- 自动下载默认关闭；更新不会静默安装，必须由用户确认“立即安装并关闭”。
- 更新会保留 data/（文献库、设置、来源等）；安装前会额外备份数据库和设置，程序文件备份保留最近一个旧版本。
- 安装期间请勿强制结束进程；若安装失败，下次启动会提示并保留 apply.json/日志供重试。
- 需要 Windows 10.0.17763 或更高版本、x64；桌面窗口依赖 Microsoft Edge WebView2 运行时。
- 本版本未做 Authenticode 代码签名，Windows SmartScreen 可能提示；请从官方 Release 下载并核对 SHA256SUMS。
- 支持从旧版本（含 1.6/1.7.1）升级；更新包不包含用户数据。
- 发布资产：PaperLibrary.v1.8.Nexus.zip、update-manifest.json、SHA256SUMS、release-v1.8.json；完整包与清单均可在 GitHub Release 下载。
