## 3. 已知偏差与原因（验收时看这一节）

1. **前端 5 个视图文件超过 600 行**：pdfviewer 1,597 / search 1,538 / detail 1,528 / settings 1,079 / edit 883。
   这些是 Sci-lib P4 的既有文件（批次 1 摘要已列为 backlog），本阶段没有拆分（拆分风险大于收益）。
   后端与新增文件全部 ≤600（query 547 / boolean_query 580 / migrate 600 贴线）。
2. **契约快照只校验顶层键**：69 行快照只比较状态类 + 顶层 JSON 键；深层字段用 tools/e2e.py 的 37 步 Node 参照 diff 覆盖
   （0 差异）。未进 e2e 的端点（附件/上传/SSE/导入）由 test_files/test_ai/test_chat/冒烟覆盖，不保证与 Node 逐字节一致。
3. **旧库图表包含非图表图片**：从 PaperLibrary 迁移的 1,441 张图沿用原提取结果（含作者照片、出版社按钮图）。
   新建/重提图表走图注 bbox 匹配（质量更好）；画廊默认不过滤，属数据保真 vs 观感的取舍。
4. **纯函数两处有意偏离 JS**：① JS text-repair 词首连字替换参数错位（$4 字面量）会写坏正文，Python 按意图修复；
   ② 真连字字形 ﬁ/ﬂ 先归一（否则全文搜不到）。两处都写在 test_pure_parity.py 的 known-divergence 用例里。
5. **Obsidian 导出带 media**：按契约 §10 把引用到的图表放进 zip，真实库全量导出约 275MB（1,441 图）。
   若只需要笔记，可后续加 noMedia 参数（本阶段不做，避免改契约）。
6. **未移植的旧模块**（有意）：figures_arxiv（依赖外网 e-print，与离线冲突）、thumbs（无缩略图端点）、
   api_manager/tunnel/file_server/folder_picker/start_all（Streamlit/Tk/隧道专用）。
7. **未迁移的旧表**：compare_cache（0 行）、custom_categories（1 行，无业务字段）。
8. **全文索引懒建**：启动不建倒排（省冷启动），首次 fulltext 检索时建；stats().tokens 在首次检索前为 0。
