PaperLibrary v1.6 Nexus（Nexus 文献库）
========================================

一、启动（双击 PaperLibrary.exe）
  双击后：稍等片刻（首次启动约几秒）→ 打开自带的「PaperLibrary v1.6 Nexus」窗口，
          界面就在这个窗口里（内置 Microsoft Edge WebView2，不再打开外部浏览器标签页）。
  服务在后台运行（pythonw，无控制台窗口）；关闭窗口时会保存数据、停止服务并释放端口。
  自动停止：如果没有窗口/网页连着，30 秒后服务会自己保存数据并退出
            （想改时间：启动参数 --idle-exit 秒数，0 = 不自动停）。
  仍想用浏览器：在命令行运行
            runtime\portable\python.exe -m paperlib --port 4321
          会像以前一样用默认浏览器打开 http://127.0.0.1:4321/ 。

  整理文献：左侧栏「分类文件夹」里，点标题可折叠/展开，＋ 新建目录、⚙ 管理（改名/删除）；
            改单篇的分类：列表里每篇最左边（星标右边）的文件夹按钮，或卡片/详情页里的分类胶囊；
            改多篇：列表顶部「批量」→ 勾选 → 底部条「移动到目录」；
            导入或编辑文献时也能选目录，还支持一次把整批放进同一个目录。
  不会操作时：点左侧栏底部、「使用文档」上面的「💬 智能问答助手」，
            左下角会弹出对话框，问完点 ✕ 或再点一次入口收起，页面上不留浮标。
            没配大模型时是离线问答：问操作、问库藏都能答，还带四条快捷提问；
            配了大模型后还能自由提问，它会检索库内文献回答并给出引用来源。
  不会用的时候：点左侧栏最下方的「📖 使用文档」，里面有完整的新手手册
                （环境准备 → 逐步操作 → 参数解释 → 排错 → 示例）。

  如果窗口没有出现：
    · 看 data\logs\launcher.log 里的原因
    · 确认系统装有 Microsoft Edge WebView2 运行时（Windows 11 自带；Win10 装了新版 Edge 一般也有）
    · 启动失败或 4321 被占用时会弹窗说明，不会静默退出
    · 或在命令行里直接运行（窗口里会显示错误）
        runtime\portable\python.exe -m paperlib --port 4321 --no-open

二、Windows「无法验证发布者」提示怎么处理
  发布包没有购买代码签名证书：从网络下载的 zip 解压后，Windows 会给包内文件打上
  「网络来源」标记，首次双击 PaperLibrary.exe 时可能弹出「打开文件 - 安全警告」。
  这不是病毒，两种处理：
    1) 首次运行前：右键 zip 文件 → 属性 → 勾选「解除锁定」→ 确定，再解压（推荐）；
       或对解压目录运行 PowerShell：
         Get-ChildItem -Recurse | Unblock-File
    2) 已弹出时：点「运行(R)」即可（只信任你自己的下载来源）。
  说明：同一份文件点过一次「运行」后不会再弹；用 PowerShell 的 Expand-Archive 或系统
  自带的 tar 解压通常不会带上该标记（资源管理器解压会）。代码签名证书才能从根本上消除。

三、数据位置
  data\library.db          文献库（SQLite，唯一真源）
  data\article\papers\     原文 PDF
  data\article\attachments\ 补充材料
  data\images\             图表图片
  data\prefs.json          界面偏好
  data\settings.json       大模型配置（含 API Key，明文，只在本机）
  data\websearch.json      网络检索配置（Exa）
  data\sources.json        外部题录源配置（OpenAlex）
  data\backups\            自动备份
  data\webview2\           内置窗口的缓存与窗口内偏好（可删，删了会重置）
  data\logs\               启动/运行日志

  迁移旧库：把旧的 data\library.json（Sci-lib）或 data\papers.db（PaperLibrary）
  放到 data\ 下，启动时会自动合并；建议先备份整个 data\ 目录。

四、离线
  入库、检索、阅读 PDF、引用、图表浏览、深度分析（无 Key 本地降级）、Obsidian 导出
  均可离线使用。联网功能（外部检索、题录抓取、大模型总结/对话）需要网络与相应 Key。

五、隐私
  data\ 目录只在本机，不会上传。分享或发布时不要包含 data\ 与 runtime\（如有 API Key）。

六、常见问题
  打不开页面/窗口空白：先看 data\logs\launcher.log；确认已装 WebView2 运行时；确认 4321 没有被别的程序占用；
             需要换端口时在命令行运行：
               runtime\portable\python.exe -m paperlib --port 4322 --no-open
  公式不显示：vendor\katex 缺失时会降级为原文显示，不影响文献功能。
  内置阅读器空白：vendor\pdfjs 缺失时自动回退浏览器自带查看器。
